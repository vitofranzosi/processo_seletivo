{% comment %} **A publicação no próprio gesto de convocar** (159, FR-6801, FR-6802, FR-6816). O que será público, a autoridade que assina e, na forma por publicação, a declaração do veículo — no formulário que convoca, e não num segundo percurso. O veículo vai no botão que a pessoa aperta (D-006): nenhum dos dois é presumido. Recebe: `escolha` (as autoridades de `_escolha_da_autoridade`), `publicacao` (a forma é a publicação), `registro` (o registro de uma publicação feita fora do GPS), `sufixo` (para os identificadores não se repetirem entre os formulários da tela) e `autoridade_escolhida`. {% endcomment %}
