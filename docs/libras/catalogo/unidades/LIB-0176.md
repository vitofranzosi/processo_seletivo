# LIB-0176 — Cadastro no Gov.br para a inscrição

> Família **INS** (Inscrição) · Classificação documental: **INÉDITA** · Origem: **D** · Complexidade linguística preliminar: **baixa**
>
> A classificação diz respeito ao potencial de reutilização **documental**. Ela não aprova reutilização audiovisual, que depende de tradução validada por profissional de Libras.

## Finalidade

Dizer que a inscrição passa pelo cadastro no Gov.br.

## Texto de origem

**Ocorrências com este texto:** 28/2026 5.1.2 (p. 4)

> 5.1.2 Para realizar a inscrição, o candidato será direcionado para o site do Gov.Br, onde deverá realizar o cadastro (caso não tenha conta) ou atualizar suas informações de cadastro.
