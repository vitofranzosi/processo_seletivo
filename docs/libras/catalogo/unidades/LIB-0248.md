# LIB-0248 — Análise dos documentos dos suplentes, por código de vaga

> Família **CLA** (Classificação) · Classificação documental: **PARAMETRIZÁVEL** · Origem: **D** · Complexidade linguística preliminar: **média**
>
> A classificação diz respeito ao potencial de reutilização **documental**. Ela não aprova reutilização audiovisual, que depende de tradução validada por profissional de Libras.

## Finalidade

Dizer quantos suplentes têm documentos analisados.

**Texto 1** — 28/2026 8.12 (p. 12)

**Texto 2** — 59/2026 6.10 (p. 6)

> 6.10 Para cada código de vaga, haverá a análise dos documentos de até 30 (trinta) suplentes para chamada imediata, em caso de desistência de alunos matriculados.
