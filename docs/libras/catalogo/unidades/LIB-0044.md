# LIB-0044 — Convocação para verificação da autodeclaração (heteroidentificação) *(desdobrada)*

> **Desdobrada na rodada 2.** Esta unidade não recebe ocorrências novas. O identificador fica, para que as referências da versão 1 do catálogo continuem resolvendo. Sucessoras: [LIB-0131](LIB-0131.md) Verificação da autodeclaração: só os sorteados para vagas reservadas, [LIB-0146](LIB-0146.md) Heteroidentificação de todos os autodeclarados pretos ou pardos.

## Por que foi desdobrada

O 91 convoca só os sorteados para vagas reservadas a pretos e pardos; o 92 submete todos os autodeclarados pretos ou pardos, por comissão própria. Destinatários diferentes.

## Ocorrências na versão 1 do catálogo

E91-064, E92-175. Cada uma passou a uma das sucessoras; as linhas de cobertura são as mesmas.

- **Impedimentos:** O público difere (sorteados × todos os autodeclarados).
