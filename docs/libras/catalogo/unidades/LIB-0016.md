  - percentual

- **Ordem lógica das informações (como no texto de origem; a tradução pode reorganizar):** Linha a linha.
- **Contexto a fornecer ao tradutor:** Agrupada por identidade (068, ED-11): uma tabela para todos os Perfis quando são iguais, uma por Perfil quando diferem (01/2026). Coluna vazia é omitida. Os nomes das modalidades são termos do glossário; os fundamentos são citações legais longas.
- **Elementos visuais de apoio:** Tabelas pedem decisão de tratamento visual (a tabela na tela, uma linha por vez, ou outra).
- **Observações de montagem:** Tabelas, frases de reversão e de convocação e blocos de Perfil se referem uns aos outros.
