# LIB-0310 — Termo de dados: compartilhamento

> Família **ANX** (Anexos: formulários, declarações e termos) · Classificação documental: **INÉDITA** · Origem: **D** · Complexidade linguística preliminar: **média**
>
> A classificação diz respeito ao potencial de reutilização **documental**. Ela não aprova reutilização audiovisual, que depende de tradução validada por profissional de Libras.

## Finalidade

Autorizar o compartilhamento necessário.

## Texto de origem

**Ocorrências com este texto:** 28/2026 Anexo VI, compartilhamento (p. 22–23)

> Compartilhamento de Dados O Controlador fica autorizado a compartilhar os dados pessoais do Titular com outros agentes de tratamento de dados, caso seja necessário para as finalidades listadas neste termo, observados os princípios e as garantias estabelecidas pela Lei no 13.709.
