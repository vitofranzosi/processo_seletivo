## Roteiro de produção

- **Objetivo comunicativo:** Abrir o bloco de um Perfil e dizer qual é.
- **Informações obrigatórias:**

  - qual é o Perfil
  - a descrição, quando houver

- **Ordem lógica das informações (como no texto de origem; a tradução pode reorganizar):** Item, código, nome, descrição.
- **Contexto a fornecer ao tradutor:** O item é posicional (seção.ordem). Código e nome são digitados; a descrição é texto livre. O código é identificador de sistema; o que identifica o Perfil para a pessoa é nome e localidade.
- **Elementos visuais de apoio:** Tabelas pedem decisão de tratamento visual (a tabela na tela, uma linha por vez, ou outra).
- **Observações de montagem:** Tabelas, frases de reversão e de convocação e blocos de Perfil se referem uns aos outros.
