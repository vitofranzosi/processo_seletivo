# LIB-0247 — Autodeclarados sorteados na ampla não contam nas reservadas

> Família **CLA** (Classificação) · Classificação documental: **INÉDITA** · Origem: **D** · Complexidade linguística preliminar: **média**
>
> A classificação diz respeito ao potencial de reutilização **documental**. Ela não aprova reutilização audiovisual, que depende de tradução validada por profissional de Libras.

## Finalidade

Dizer que o cotista classificado na ampla libera a vaga reservada.

## Texto de origem

**Ocorrências com este texto:** 28/2026 8.9 (p. 11)

> 8.9 Os candidatos autodeclarados negros e indígenas sorteados dentro do número de vagas oferecido para ampla concorrência não serão computados para efeito do preenchimento das vagas reservadas, isto é, não constarão na lista de classificados como autodeclarados, abrindo vaga para o próximo suplente autodeclarado.
