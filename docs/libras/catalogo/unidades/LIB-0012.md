# LIB-0012 — Remissão aos requisitos específicos do Perfil

> Família **REQ** (Requisitos de participação) · Classificação documental: **SEMELHANTE** · Origem: **D** · Complexidade linguística preliminar: **baixa**
>
> A classificação diz respeito ao potencial de reutilização **documental**. Ela não aprova reutilização audiovisual, que depende de tradução validada por profissional de Libras.

## Finalidade

Dizer que, além dos gerais, valem os requisitos do Perfil escolhido.

## Texto de origem

**Texto 1** — 91/2026 4, §1 (p. 1)

> Para se inscrever, o candidato deverá atender aos requisitos do polo pretendido, descritos na seção Perfis de Vaga.

**Texto 2** — 92/2026 2.4 (p. 1)

> 2.4 Possuir os requisitos específicos do perfil pretendido, descritos neste Edital.

- **Condições de equivalência:** **Equivalência provável:** “do polo pretendido” (91) e “do perfil pretendido” (92) designam o mesmo — o Perfil escolhido —, com vocabulário diferente; confirmar.
- **Situações que impedem reutilização:** Nenhum identificado; a diferença é de vocabulário.

## Roteiro de produção

- **Objetivo comunicativo:** Dizer que, além dos gerais, valem os requisitos do Perfil escolhido.
- **Informações obrigatórias:**

  - que os requisitos do Perfil também valem
  - onde estão

- **Ordem lógica das informações (como no texto de origem; a tradução pode reorganizar):** Única frase.
- **Contexto a fornecer ao tradutor:** 91: “do polo pretendido, descritos na seção Perfis de Vaga”; 92: “do perfil pretendido, descritos neste Edital”. Remissão interna, pelo nome da seção.
- **Elementos visuais de apoio:** Possíveis: a lista de requisitos na tela.
- **Observações de montagem:** Cada requisito é uma condição própria; a lista vale para o Perfil ou o grupo indicado antes dela.
