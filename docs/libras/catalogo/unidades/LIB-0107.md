# LIB-0107 — Atendimento especializado à pessoa com deficiência

> Família **AFI** (Ações afirmativas e acessibilidade) · Classificação documental: **INÉDITA** · Origem: **D** · Complexidade linguística preliminar: **média**
>
> A classificação diz respeito ao potencial de reutilização **documental**. Ela não aprova reutilização audiovisual, que depende de tradução validada por profissional de Libras.

## Finalidade

Dizer como pedir atendimento especializado para participar das etapas.

## Texto de origem

**Ocorrências com este texto:** 92/2026 7, §1 (p. 11)

> O candidato com deficiência que necessitar de atendimento especializado para participar das etapas deverá solicitá-lo no formulário de inscrição, indicando os recursos necessários.
