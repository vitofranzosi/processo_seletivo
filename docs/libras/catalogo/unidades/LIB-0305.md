# LIB-0305 — Termo de dados: o que o documento registra

> Família **ANX** (Anexos: formulários, declarações e termos) · Classificação documental: **INÉDITA** · Origem: **D** · Complexidade linguística preliminar: **média**
>
> A classificação diz respeito ao potencial de reutilização **documental**. Ela não aprova reutilização audiovisual, que depende de tradução validada por profissional de Libras.

## Finalidade

Dizer que o termo registra o consentimento para finalidade específica, conforme a LGPD.

## Texto de origem

**Ocorrências com este texto:** 28/2026 Anexo VI, finalidade do termo (p. 22)

> ANEXO VI - TERMO DE CONSENTIMENTO PARA TRATAMENTO DE DADOS PESSOAIS Este documento visa registrar a manifestação livre, informada e inequívoca pela qual o Titular (ou seu Representante Legal) concorda com o tratamento de seus dados pessoais para finalidade específica, em conformidade com a Lei no 13.709 – Lei Geral de Proteção de Dados Pessoais (LGPD).
